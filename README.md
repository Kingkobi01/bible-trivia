# Bible Trivia

A single-file, Notion-styled Bible trivia app for hosting quizzes on congregation trips, at home, or in a hall. Open `index.html` in any browser — no build step required.

## Pages

- **🎤 Host Console** — read questions aloud, toggle the multiple-choice options, reveal the answer with its explanation and scripture, run a countdown timer, and keep score for up to 4 teams (names and scores are saved in your browser). Includes a full-screen **Present** mode for projectors/TVs.
- **🎯 Solo Quiz** — play through all 50 questions (in order or shuffled) with instant feedback and an end-of-quiz breakdown by difficulty.
- **📚 Question Database** — searchable, filterable table of every question, answer and reference, plus quick insights by theme and difficulty. Answers can be blurred to avoid spoilers.

## Keyboard shortcuts

| Where | Keys |
| --- | --- |
| Anywhere | `1` `2` `3` switch pages |
| Host Console | `←` `→` navigate · `Space` reveal/hide answer · `O` toggle options · `T` start 30s timer · `P` present · `Esc` exit present |
| Solo Quiz | `1`–`4` answer · `Enter` next question |

Light and dark themes are supported (follows your system setting, toggle in the sidebar).
